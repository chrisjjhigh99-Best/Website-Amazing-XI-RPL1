## Cara Ganti Foto

1. Simpan foto siswa di `assets/img/siswa/` dengan nama NIS, misalnya `16919.jpg`.
2. Di `index.html`, ubah `assets/img/siswa/16919.svg` menjadi `assets/img/siswa/16919.jpg`.
3. Foto wali kelas ada di `assets/img/wali-kelas/`.
4. Ukuran foto terbaik: rasio 4:5 (contoh 400 x 500 px).
